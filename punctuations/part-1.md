## Japanese punctuation notes

| Function         | Japanese convention | Example           |
| ---------------- | ------------------- | ----------------- |

| Comma pause      | 、(tōten)            | 私は東京へ行き、友達に会いました。 |
| Question         | ？                   | 元気ですか？            |
| Exclamation      | ！                   | すごい！              |
| Quotation        | 「 」                 | 「ありがとう」と言いました。    |
| Nested quotation | 『 』                 | 『源氏物語』を読みました。     |
| Enumeration      | ・                   | 東京・大阪・京都          |
| Ellipsis         | …                   | どうしよう…            |
